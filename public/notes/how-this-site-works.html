How this site works

November 2026 · 2 min read

This site is a résumé and a small AI application. The assistant lets you ask about my projects and experience without reading the whole page.

One Worker and a written profile

A Cloudflare Worker serves the pages and a /api/chat endpoint that streams answers from Claude. The model receives a written profile of my background, maintained alongside the résumé.

Its instructions require it to answer from that profile, identify missing information, and refer questions to my email when needed. It speaks about me in the third person. AI answers can still be wrong.

Usage limits

A Durable Object tracks a global daily message count. A separate limit controls requests per IP address, and the server limits message length and conversation history. These constrain usage; they don’t set a fixed dollar budget.

Application logs record question text without adding an IP address to that entry. Please don’t include personal or confidential information in a question.

The visuals on the homepage

The payroll example uses fictional data to illustrate source-linked findings and human review. The platform diagram is conceptual. Neither reproduces an internal product screen.
